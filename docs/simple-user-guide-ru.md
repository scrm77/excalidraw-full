# Как пользоваться Draw Meatbags

Самый простой безопасный сценарий:

1. Откройте `draw.meatbags.ru` и войдите общим логином `draw-guest` с паролем, который дал владелец. Владелец также может войти своим аккаунтом.
2. Рисуйте как в обычном Excalidraw.
3. Откройте меню слева сверху и выберите **Save as New Canvas…**.
4. Дайте доске понятное имя и сохраните её.
5. Откройте боковую панель с иконкой папки: там находятся ваши сохранённые доски.

По умолчанию доски хранятся только в этом браузере. Они переживут перезагрузку страницы, но могут исчезнуть при очистке данных браузера или при работе на другом компьютере.

Чтобы хранить доски на личном сервере:

1. В меню выберите **Login** и войдите своим личным аккаунтом через Authentik на `auth.meatbags.ru`. Общий `draw-guest` открывает редактор, но не даёт личного серверного каталога.
2. В меню откройте **Data Source Settings…**.
3. Выберите **My server (online)** и нажмите **Save**.
4. Создайте новую серверную доску через **Save as New Canvas…**.

Важно: переключение места хранения не переносит старые доски автоматически. Если доска важна, дополнительно скачайте файл через меню **Save to file** — его можно снова открыть в Excalidraw и передать AI-агенту.

## Гости и ссылки

- **My Creations без личного входа** показывает доски этого браузера. Общий пароль не объединяет локальные доски разных людей и не открывает гостю личный каталог владельца.
- **Export to Link** создаёт на сервере зашифрованный снимок. Получатель может открыть и редактировать свою копию, но изменения не обновляют исходную доску или уже созданный снимок.
- **Live collaboration** — отдельная совместная сессия по секретной ссылке. Получателю также нужен общий вход. В текущем сервере состояние комнат хранится в оперативной памяти и теряется при перезапуске. Это не постоянная общая доска с управлением доступом.

Для анонимных снимков действуют ограничения: 5 МиБ на запрос, 20 созданий в час на клиента и 100 суммарно в час. Общей квоты хранилища и автоматического удаления старых снимков пока нет. Эти ограничения не распространяются на хранилище совместных комнат; ему также нужны отдельные ограничения ресурсов.
