# Как пользоваться Draw Meatbags

Самый простой безопасный сценарий:

1. Откройте `draw.meatbags.ru`.
2. Рисуйте как в обычном Excalidraw.
3. Откройте меню слева сверху и выберите **Save as New Canvas…**.
4. Дайте доске понятное имя и сохраните её.
5. Откройте боковую панель с иконкой папки: там находятся ваши сохранённые доски.

По умолчанию доски хранятся только в этом браузере. Они переживут перезагрузку страницы, но могут исчезнуть при очистке данных браузера или при работе на другом компьютере.

Чтобы хранить доски на личном сервере:

1. В меню выберите **Login** и войдите через разрешённый GitHub-аккаунт.
2. В меню откройте **Data Source Settings…**.
3. Выберите **My server (online)** и нажмите **Save**.
4. Создайте новую серверную доску через **Save as New Canvas…**.

Важно: переключение места хранения не переносит старые доски автоматически. Если доска важна, дополнительно скачайте файл через меню **Save to file** — его можно снова открыть в Excalidraw и передать AI-агенту.
